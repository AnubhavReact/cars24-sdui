# Raw prompt log

Append every meaningful AI prompt here as you work, in order, with a one-line
note on what you kept / rejected. Curate the best three (+ the one failure)
into `AI_WORKFLOW.md` at the end. Don't try to reconstruct this from memory
later.

Format:

```
## <date/time> — <short topic>
Prompt: ...
Outcome: what it produced
Kept/Rejected: what you kept, what you rewrote, why
```
